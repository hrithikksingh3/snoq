# SNOQ local setup

## Prerequisites

Use Node 22 LTS, PostgreSQL (Neon is supported), and a Cloudinary account for document storage. Gemini/OpenRouter, Resend, Twilio, Google OAuth, and Razorpay are optional locally but required for the corresponding production features.

## Install and run

1. Run `npm install` from the repository root.
2. Copy `server/.env.example` to `server/.env`.
3. Copy `client/.env.example` to `client/.env.local`.
4. Set `DATABASE_URL` and a unique `JWT_SECRET` of at least 32 characters in `server/.env`.
5. Generate Prisma and apply development migrations:

   ```bash
   npm run db:generate
   npm run db:migrate
   ```

6. Optionally seed starter categories with `npm run db:seed`.
7. Start both services with `npm run dev`.

The client runs on port 5173 and the API on port 4000 by default.

The local API readiness endpoint is `http://localhost:4000/health`. It returns only `{ "ok": true }` and does not require an account.

Before opening a pull request or deploying, run the local release checks:

```bash
npm run typecheck
npm run lint
npm test
npm run build
npm audit --omit=dev
```

## Environment configuration

### Core

- `DATABASE_URL` — PostgreSQL connection URL.
- `JWT_SECRET` — at least 32 unpredictable characters; never reuse between environments.
- `FRONTEND_URL` and `BACKEND_URL` — exact browser and API origins.
- `COOKIE_SECURE` — `false` locally and **`true` in production**.
- `ADMIN_EMAIL` — the email address that should receive the `ADMIN` role on sign-in.

### Storage and AI

- Cloudinary: `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`, and optional folder names.
- AI: choose `AI_PRIMARY_PROVIDER=gemini` or `openrouter`; configure only the matching provider key/model. `AI_FALLBACK_PROVIDER` may name the other configured provider.

### Email, SMS, billing, and OAuth

- Resend: `RESEND_API_KEY`, `EMAIL_FROM`. Verify the sender domain before testing deliveries outside the provider account.
- Twilio: `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM_NUMBER` for optional coupon SMS broadcasts.
- Razorpay: `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET`, `RAZORPAY_WEBHOOK_SECRET`. Local webhooks need a secure tunnel or a provider-supported test setup.
- Google: set `GOOGLE_CLIENT_ID` on the server when Google sign-in is enabled. The login page reads this public identifier from the API at runtime, so no duplicate `VITE_GOOGLE_CLIENT_ID` is required. Register the exact frontend origins in Google Cloud Console.

### Safety limits

All limits are server-side and have safe defaults. Tune them for expected traffic without disabling them:

- `API_RATE_LIMIT_MAX`, `AUTH_RATE_LIMIT_MAX`, `PASSWORD_RESET_RATE_LIMIT_MAX`
- `AI_RATE_LIMIT_MAX`, `CHECKOUT_RATE_LIMIT_MAX`, `PUBLIC_ACCESS_REQUEST_RATE_LIMIT_MAX`
- `BROADCAST_RATE_LIMIT_MAX` for mass email/SMS coupon announcements
- `REPORT_RATE_LIMIT_MAX` for private administrator PDF/Excel exports
- `USER_EXPORT_RATE_LIMIT_MAX` for personal vault/list downloads and emailed PDF reports

## Administrator access and reports

Set `ADMIN_EMAIL` before that person signs in. Existing users whose email matches it are elevated during authentication. The `/admin` screen requires both a valid session and `ADMIN` role; server authorization remains the source of truth. The plan editor includes **Include private PDF, Excel, and email reports**. Enable it for the paid plans that should provide reporting; the migration disables it for the Free plan and enables it for existing paid plans.

The Admin panel can export live data as Excel or PDF. The Excel workbook contains Overview, Users, Subscriptions, and Coupons sheets. The PDF presents an executive summary, latest accounts, and coupon state. Downloads are generated by the backend and are not cached by the browser.

## Personal data exports

In **Settings → Your data reports**, a user on a plan with reports enabled can export the entire vault or one owned list. PDF and Excel downloads are generated on the server, and either format can be sent as an attachment to the current account email. The white, tabular PDF has clickable Open buttons for URL resources. The browser never supplies a recipient address. PDF exports include the newest 100 entries to keep attachments practical, while the Excel export can include up to 5,000 rows.

## Upload limits

SNOQ accepts only allow-listed document formats and practical MIME/extension pairs. Documents are capped at 15 MB; avatars are capped at 2 MB and 25 megapixels. Files are processed in memory only long enough to validate and upload them to Cloudinary.

## Troubleshooting

- **Prisma client mismatch or initialization error:** check `DATABASE_URL`, run `npm run db:generate`, then rerun the migration command. Stop local processes that are locking Prisma engine files before regenerating on Windows.
- **Login says a database update is required:** the application code is newer than the database schema. Run `npm run db:deploy -w server` against the intended database, then retry. Do not use `prisma generate --no-engine` for the direct PostgreSQL setup used by SNOQ.
- **CORS or session failures:** make `FRONTEND_URL` exactly match the browser origin. In production, use HTTPS and `COOKIE_SECURE=true`.
- **No administrator menu:** sign out and sign in again after setting `ADMIN_EMAIL`; confirm the exact email address matches.
- **Email does not arrive:** verify the Resend domain and sender identity; development/test sender identities are intentionally restricted by providers.
- **Razorpay changes do not activate a plan:** check the signed webhook configuration and API logs. A plan is activated only after a verified webhook event.
- **Report download fails:** verify the account is an administrator and inspect API logs. The report route is rate-limited and requires a current authenticated session.
- **Personal report download fails:** the selected plan must have **Include private PDF, Excel, and email reports** enabled in Admin. The selected list must belong to the signed-in account.
- **Health check fails:** use `/health`, not `/api/health`. The latter is part of the protected API namespace.
